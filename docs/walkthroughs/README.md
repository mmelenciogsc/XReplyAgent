# XReplyAgent Walkthrough Package

This folder holds the capture plan, shot lists, narration drafts, generated screenshots, and final narrated walkthrough media for XReplyAgent.

Targets:

- Desktop video: `2560x1440` landscape
- Desktop screenshots: `2560x1440`
- Mobile video: `430x932` portrait
- Mobile screenshots: `430x932`

Style:

- Clean, dark, restrained, structural
- Short, exact narration
- Soft UI sounds for taps, expands, collapses, and clicks
- Ambient bed underneath the voice track
- Screen-capture only, no synthetic b-roll
- Customer flows begin on the public guest view before sign-in and end with analysis, ranked replies, history, and analytics
- Admin flows begin on admin-only surfaces and continue through review, publishing, and browser monitoring

Final assets:

- Customer desktop video: `final/customer-desktop/customer-desktop.mp4`
- Customer mobile video: `final/customer-mobile/customer-mobile.mp4`
- Admin desktop video: `final/admin-desktop/admin-desktop.mp4`
- Admin mobile video: `final/admin-mobile/admin-mobile.mp4`
- Matching captions: `final/*/*.srt`
- Manifest: `final/manifest.json`
